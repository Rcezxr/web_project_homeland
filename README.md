# Projeto | De Pátria para Pátria

Aplicação desenvolvida utilizando HTML para estrutura e semântica, CSS para estilização e responsividade, além do Figma para prototipação e definição visual.

## Tecnologias utilizadas

- HTML
- CSS
- Figma

## Funcionalidades

- Layout responsivo
- Estrutura semântica
- Interface baseada no protótipo do Figma

## Como visualizar

1. Baixe ou clone o repositório
2. Abra o arquivo `index.html` no navegador
